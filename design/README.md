# ホームページ下層4ブロックの再設計

- Figma: https://www.figma.com/design/GWAggWVaNf0L990xWhArXb?node-id=1-2
- 対象: お知らせ、新入部員募集、活動概要、見学・体験の流れ
- Figma作成用のHTML: `home-sections.html`（PC 1440px / モバイル 390px）
- 実装: `src/components/home/`、`src/home-sections.css`

紺、生成り、淡い緑の配色と明朝体を用い、見出しと本文の大小、区切り線、余白を統一する。
既存の説明、リンク先、CMSのお知らせ、木目の駒型カード、同じ寸法の立方体を引き継ぐ。
活動概要は立方体を縦にずらし、回転時の描画範囲を確保する。
背景は細い直交線を400px間隔で配置し、各要素をスクロール位置に応じて順番に表示する。
ホイールやタッチ操作のキャンセル、画面の固定、スクロール位置の強制変更は追加しない。

FigmaへのHTML取り込みは成功。一部参照APIがStarterプランの上限に達しているため、
取り込み後のFigmaレイヤー構成とFigma上のスクリーンショットの再取得は未検証。
実ページの表示・操作はT3の共有ブラウザーで確認する。

最終実装で行った見出しの折り返し等の微調整は `home-sections.html` に反映済み。
Figma側への最終再同期も同じプラン上限で実行できていない。

確認済み: プレビュービルド、JavaScript構文、差分の空白エラー、320/390/768/1024/1440px幅、
320px幅でのカード内部の収まり、立方体の等寸と非重複、見出しの追従、通常スクロール、明朝体、フッターの背景。
お知らせは実際のレンダラーによる7件の一時データでも表示と横送りを確認し、確認後に空の状態へ戻した。
公開データは追加していない。
